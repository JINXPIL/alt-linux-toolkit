# altctl — обслуживание ALT Linux одной командой

`altctl` чинит и обновляет ALT Linux без привязки к конкретной версии. Ветка (Sisyphus, p10, p11, c10f2…), архитектура, тип ядра, рабочее зеркало и имена служб определяются по самой системе при каждом запуске. Поэтому одна и та же команда работает на Simply Linux 10, Альт 11, Sisyphus и после перехода на новую ветку.

## Установка

```bash
sudo ./install.sh            # установить и включить ежедневное обслуживание в 04:00
sudo altctl doctor           # проверить систему
```

Без таймера: `sudo ./install.sh --no-timer`. Удаление: `sudo ./install.sh --uninstall`.
Можно запускать и без установки, прямо из папки: `sudo ./altctl doctor`.

## Команды

| Команда | Что делает |
|---|---|
| `altctl doctor` | диагностика: ветка, источники, ядро, место, время, службы, экран. Ничего не меняет |
| `altctl fix` | самовосстановление (список ниже) |
| `altctl update` | полное обновление: пакеты → ядро и модули → flatpak → очистка |
| `altctl kernel` | только ядро и модули к нему |
| `altctl maintain` | `fix` + `update`; именно это запускает таймер |
| `altctl repo auto` | подобрать живое зеркало под ветку системы и переписать источники |
| `altctl repo set p11` | перейти на другую ветку (затем `altctl update`) |
| `altctl repo restore` | вернуть источники, какими они были до последнего изменения |
| `altctl install mc 'apache2-base\|apache2'` | установить пакеты; `a\|b` — альтернативные имена |
| `altctl services` | установить и запустить службы из `SERVICES` |
| `altctl firewall apply\|status\|off` | межсетевой экран из настроек `FW_*` |
| `altctl timer on\|off\|status` | расписание автоматического обслуживания |

Опции: `-n` — показать, что будет сделано, ничего не меняя; `-y` — без вопросов.

## Что чинит `fix`

- **Блокировки APT.** Ждёт Synaptic или Центр приложений и снимает «мёртвые» lock-файлы. Чужие процессы не убивает.
- **Базу RPM.** Если `rpm` не читает базу, удаляет `__db.*` и выполняет `rpm --rebuilddb`.
- **Источники пакетов.** Если ветки смешаны (например, Sisyphus поверх p10), источники не совпадают с веткой системы или их нет, — переписывает их.
- **Зеркало.** Если зеркало не отвечает, `update` очищает списки пакетов и переключается на следующее из `MIRRORS`.
- **Зависимости.** Нарушенные зависимости исправляет через `apt-get -f install`.
- **Время.** Включает NTP: из-за сбитых часов не проходит проверка подписей репозиториев.
- **Место.** При нехватке места на `/` очищает кэш, при нехватке в `/boot` удаляет старые ядра.
- **Модули ядра.** Восстанавливает `modules.dep` и сообщает, если модули не загрузились.
- **Службы.** Поднимает упавшие службы из `WATCH_UNITS` и `SERVICES`.
- **Межсетевой экран.** Если `FW_ENABLE=yes`, а правила пропали, загружает их заново.

## Почему отдельно обновляется ядро

В ALT `apt-get dist-upgrade` не ставит новое ядро: версия входит в имя пакета ядра (`kernel-image-6.12-…`). Новое ядро и согласованные с ним модули (`kernel-modules-*-<тип>`) ставит `update-kernel` — `altctl update` вызывает его сам. Старые ядра удаляются только после того, как система загрузилась в новое, чтобы рабочее ядро никогда не пропало. Если нужна перезагрузка, `altctl` сообщит об этом. Перезагружаться автоматически он будет только при `AUTO_REBOOT=yes`.

## Настройки — `/etc/altctl.conf`

Все параметры собраны в одном файле с комментариями. Чаще всего меняют:

```bash
BRANCH=auto                                # или p11 / Sisyphus — закрепить ветку
SERVICES="openssh-server:sshd apache2-base|apache2:httpd2 samba:smb,nmb"
FW_ENABLE=yes; FW_TCP_PORTS="22 80"        # затем: sudo altctl firewall apply
TIMER_SCHEDULE="Sun 03:00"                 # затем: sudo altctl timer on
AUTO_REBOOT=no
```

Любой параметр можно задать разово: `sudo BRANCH=p11 altctl repo auto`.

## Где что лежит

| Путь | Назначение |
|---|---|
| `/opt/altctl/`, `/usr/local/sbin/altctl` | программа |
| `/etc/apt/sources.list.d/altctl.list` | источники, которые пишет altctl (остальные закомментированы с пометкой `#altctl#`) |
| `/var/backups/altctl/` | резервные копии источников и правил экрана |
| `/etc/sysconfig/iptables`, `ip6tables` | сохранённые правила; поднимает `altctl-firewall.service` |
| `journalctl -u altctl-maintain` | журнал автоматического обслуживания |

## Структура проекта

```
altctl            точка входа и разбор команд
install.sh        установка в систему
etc/altctl.conf   настройки по умолчанию
lib/common.sh     вывод, dry-run, итоговая сводка, конфигурация
lib/detect.sh     ветка, архитектура, ядро, текущие источники
lib/repo.sh       выбор зеркала, запись и откат источников
lib/heal.sh       самовосстановление
lib/update.sh     обновление пакетов, ядра, модулей
lib/services.sh   установка пакетов и служб
lib/firewall.sh   межсетевой экран IPv4/IPv6
lib/timer.sh      systemd-таймер
lib/doctor.sh     диагностика
```

Если файлы правились в Windows и bash ругается на `$'\r'`, выполните `sed -i 's/\r$//' altctl install.sh lib/*.sh`. `install.sh` делает это сам.
